# samples

このフォルダには **モデルやモーションをコミットしません**（`.gitignore` で `samples/` の中身は README.md 以外すべて除外しています）。

## 自分のモデルで試す

第三者が作った MMD モデルは、規約で再配布が禁止されていることが多いため、リポジトリの**外**に置くことをおすすめします。

```powershell
.\build\msvc-x64\Release\ukagaka3d.exe --model "C:\Users\<you>\Desktop\MMD\キャラ\キャラ.pmx" --motion "C:\Users\<you>\Desktop\MMD\モーション\待機.vmd"
```

PMX は、テクスチャのフォルダ構成（`tex\...` など）を配布時のままにしておいてください。テクスチャのパスは、PMX ファイルがあるフォルダを起点に解決されます。

## 再配布できる合成テストデータを作る

`make_test_assets` は libmmd を使って、箱でできた人型の PMX、待機モーションの VMD、テクスチャ、壊れたファイルを生成します。すべてプログラムで作るので、ライセンスの心配はありません。

```powershell
.\build\msvc-x64\Release\make_test_assets.exe samples\generated
# あるいは
cmake --build --preset release --target test_assets   # build\msvc-x64\test-assets に出力
```

生成されるファイル：

| パス | 内容 |
|---|---|
| `テスト用モデル\テストキャラ.pmx` | ボーン 5 本（センター／上半身／頭／左腕／右腕）、マテリアル 5 つ（うち 1 つはテクスチャが存在しない設定、1 つは半透明の光輪） |
| `テスト用モデル\tex\顔.png`、`光輪.tga`、`体.bmp` | テクスチャ（日本語のファイル名） |
| `テスト用モデル\物理テストキャラ.pmx` | 上のモデルの頭の後ろに、水平に伸びる 3 節のポニーテール（剛体 4、ジョイント 3）を足したもの。物理 ON では重力で垂れ、OFF では水平のまま |
| `モーション\腕下ろしテスト.vmd` | T ポーズから 2 秒かけて腕を下ろし、そのまま保持する（マントなどの検証用） |
| `モーション\待機テスト.vmd` | 4 秒でループする待機モーション。MMD の標準ボーン名を使っているので、T ポーズの一般的なモデルにも使える |
| `broken\*.pmx`、`broken\*.vmd` | エラー処理を確認するための壊れたファイル |
