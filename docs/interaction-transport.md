# 3D マウスイベントの送信

作者向けの判定設定・イベント表は [クリック・なで・ドラッグ](author-guide/03-interactions.md) を参照してください。

1. SAORI が `ukagaka3d.json` の `interaction` を許可フォルダ内のパスに解決し、ランタイムへ渡します。設定なしのゴーストでは従来どおり左ダブルクリックを SSP シェルへ転送します。
2. ランタイムの UI スレッドがウィンドウ内座標からカメラの近面と遠面を逆投影します。現在の PMX ボーン変換で中心を動かした球とレイを交差させ、優先度、交差距離、定義順で部位を決めます。透明ウィンドウのクリック透過には既存の描画アルファの非同期プローブを使います。
3. 入力の状態機械は Windows のダブルクリック通知を使い、単クリックの通知をダブルクリック設定時間だけ保留します。マウス移動は約 67 ms に1回までに絞り、押下と捕捉の状態をなで判定に反映します。
4. 送信スレッドは SSP の `SakuraUnicode` FMO の `ghostpath` から一致するゴーストの `hwnd` を取得し、ランタイムの起動元 PID と照合します。見つからない、または候補が曖昧な場合は送信しません。
5. そのウィンドウ宛てに `WM_COPYDATA`（`dwData=9801`）で UTF-8 の `SEND SSTP/1.4` を送信します。SSP は SHIORI の戻り値をバルーンで表示します。送信キューは最大32件で、連続した移動イベントを集約し、混雑時は移動を先に捨てます。送信待ちの上限は250 msで、再送はしません。

名前付きパイプの既存の制御コマンドは引き続き SAORI から利用できます。

[Direct SSTP 仕様](https://ukatech.shillest.net/ukadoc-spec/spec/sstp/) · [FMO 仕様](https://ukatech.shillest.net/ukadoc-spec/spec/fmo-mutex/)
