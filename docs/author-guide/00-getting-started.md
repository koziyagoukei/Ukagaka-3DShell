# 00 最初の 3D ゴーストを起動する

ukagaka3d は、SSP の会話バルーンと PMX モデルを組み合わせるための 3D シェル基盤です。まず Uka サンプルを動かすと、モデル、モーション、辞書の配置を確認できます。

| 役割 | 使用するもの |
|---|---|
| ゴーストを起動し、会話を表示 | SSP |
| イベントを受けて会話を決める | SHIORI（サンプルは YAYA 6） |
| 辞書の指示を 3D ランタイムへ送る | `ukagaka3d_saori.dll`（x86） |
| 描画・動作・マウス判定 | `3d/ukagaka3d.exe`（x64） |

モデルに触れると、3D ランタイムから SSP にイベントが戻り、SHIORI が返した会話を SSP が表示します。

## 用意するもの

- Windows 10 または 11 の x64 環境、Direct3D 11 の機能レベル 11.0 以上。ハードウェア描画が利用できない場合はソフトウェア描画を試します。
- SSP と、Uka サンプルの NAR または組み立て済みフォルダ。サンプルには YAYA 6、SAORI、ランタイム、透明シェル、辞書、PMX、テクスチャ、VMD が入ります。
- ソースから組み立てる場合は Visual Studio または Build Tools の C++ デスクトップ開発環境と、YAYA 6 の `yaya.dll` とライセンスが必要です。[ビルド手順](../build.md) · [サンプルの組み立て](../sample-ghost.md)

## 最初の操作

1. SSP に NAR をドラッグしてインストールします。組み立て済みフォルダは `ssp.exe --ghost "C:\path\to\ukagaka3d_sample"` でも起動できます。
2. SSP の「ゴースト切り替え」で `ukagaka3d sample` を選びます。3D の Uka と「こんにちは。」のバルーンが出ます。
3. 髪の上の方を左クリックします。会話が出るまで Windows のダブルクリック判定時間だけ待ちます。同じ場所でボタンを押さずに数回往復すると、なでの会話が出ます。
4. 胴体をダブルクリックしてメニューを開き、「デスクトップ行動」から歩行を試します。
5. メニューの「ゴーストを終了」で閉じます。

次は [PMX の差し替え](01-models.md) または [クリック・なでの設定](03-interactions.md) へ進んでください。
