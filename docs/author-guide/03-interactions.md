# 03 クリック・なで・ドラッグ

## 当たり判定を作る

サンプルでは `ghost/master/ukagaka3d.json` の `"interaction": "hit-regions.json"` が、同じフォルダにある当たり判定ファイルを読み込みます。変更後はゴーストを起動し直してください。

次の例は Uka の頭に球を2つ置きます。まず頭だけ試すときは、`hit-regions.json` 全体をこの内容にできます。

```json
{
  "mouseMove": true,
  "pet": { "distance": 56, "minSegment": 4, "windowMs": 1400, "turns": 2, "cooldownMs": 1500 },
  "regions": [
    { "name": "Head", "bone": "頭", "offset": [0, 1.65, -0.15], "radius": 1.7, "priority": 20 },
    { "name": "Face", "bone": "頭", "offset": [0, 0.9, -1.05], "radius": 0.85, "priority": 30 }
  ]
}
```

- `name` は辞書に渡す判定名です。Head、Face、Bust、Hand、Arm、Leg、Body はサンプルの名前です。同じ名前の球を左右の手などに置けます。
- `bone` は PMX のボーン名（日本語欄または英語欄）。`offset` は基本姿勢のモデル座標でのボーンからのずれで、順に X、Y、Z です。球の中心はそのボーンの移動と回転に追従します。カメラ正面から見て通常は Y が上、負の Z が手前です。`radius` は PMX の座標単位で指定します。
- `priority` が大きい球を優先します。同じ優先度ならカメラに近い球を使います。優先度の省略時は 0、オフセットの省略時は `[0, 0, 0]` です。部位は最大128球です。
- 描画の透明部分はクリック透過します。モデル上で球に当たらなければ、取得できた描画の不透明ピクセル上では空の部位名になる場合があります。メッシュや材質を直接部位として指定する機能は未実装です。

## 辞書で反応する

サンプルの `ghost.dic` にある同名関数を置き換えるか、既存の関数へ条件を足します。

```c
OnMouseClick
{
    if reference[3] == "0" && reference[4] == "Head" && reference[5] == "0" {
        _ok = Set3DMorph("笑い", 0.7)
        return "\0頭に触れましたね。\e"
    }
    return ""
}

OnUk3dPet
{
    if reference[4] == "Head" {
        return "\0なでてもらうと落ち着きます。\e"
    }
    return ""
}
```

### イベント名

| 名前 | 種別 | 発生時 |
|---|---|---|
| `OnMouseClick` | SHIORI 標準 | 短い左クリック。ダブルクリックの判定時間が過ぎてから送信 |
| `OnMouseDoubleClick` | SHIORI 標準 | Windows がダブルクリックと判定した同一部位の2回の左クリック。単クリックの会話は重複しない |
| `OnMouseMove` | SHIORI 標準 | モデル上でボタンを押さず移動。約15回/秒まで。 `mouseMove` が `false` なら送信を止める |
| `OnUk3dPet` | 独自 | 同じ部位を往復してなで条件を満たしたとき |
| `OnUk3dDragStart` | 独自 | 長押しと Windows のドラッグ距離を満たしたとき |
| `OnUk3dDragEnd` | 独自 | ドラッグ開始後にボタンを離すか、マウスの捕捉が解除されたとき |

| Reference | 内容 |
|---|---|
| 0、1 | 3D ウィンドウの左上を原点とする X、Y（物理ピクセル） |
| 2 | `0`。ホイール量なし |
| 3 | `0`。本体側 |
| 4 | 判定名。ドラッグ開始・終了は押し始めの部位 |
| 5 | `0`。標準イベントでは左ボタン、移動では固定値 |
| 6 | `mouse` |

この表は 3D から送信するイベントの値です。標準イベントは SSP の2Dシェルからも発生し得ます。[SHIORI 標準イベント一覧](https://ukatech.shillest.net/ukadoc-spec/list/shiori-event/)

## なでの感度とドラッグ

ボタンを押さず、同じ名前の部位の上で往復します。別の部位に入る、モデルから外れる、時間内に往復できない、いずれかのボタンを押す、のいずれかで計測をやり直します。ドラッグ中はなでイベントを送信しません。

小さな部位を大きな部位の中に置くと（サンプルの頭の中の `Face` など）、その高さで横に往復するたびに部位が切り替わり、なでは成立しません。なでてほしい場所は、同じ名前の球だけで覆ってください。髪の毛の隙間のような小さな透明部分は、カーソルが 80ms 以上とどまるまでクリック透過にしないので、通り過ぎてもなでは途切れません。

| 設定 | 意味 |
|---|---|
| `distance` | 必要な移動距離の合計（96 DPI 換算 px）。小さくすると短い往復で反応 |
| `minSegment` | 一度の移動として数える最小距離（96 DPI 換算 px）。大きくすると細かい揺れを無視 |
| `windowMs` | 往復を数える時間（ms）。この時間内に `turns` 回折り返すと成立する。大きくすると、ゆっくりしたなでにも反応する。サンプルの 1400 では、片道 0.15〜0.7 秒の往復で反応することを確認済み |
| `turns` | 約120度以上の方向転換の回数 |
| `cooldownMs` | なでが発生したあと次の判定を始めるまでの時間（ms） |

既存の `OnMouseMove` でなでを数える辞書に `OnUk3dPet` を追加する場合は、なで反応をどちらかのイベントにまとめます。なでだけが必要なら `"mouseMove": false` で移動通知を止められます。

長押しするとつまみモーションが始まります。ドラッグで実際に動き始めるには、ボタンを押したまま Windows のドラッグ距離を越える必要があります。右クリックは SSP のメニュー、Shift＋右クリックは 3D のメニューです。
