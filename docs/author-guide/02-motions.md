# 02 モーションと表情

## VMD を置く

サンプルでは VMD を `ghost/master/3d/motion/` に置きます。辞書からは拡張子なしで呼べます。ボーン名が PMX と一致する VMD を使ってください。

| サンプルのファイル | 用途 |
|---|---|
| `idle.vmd` | 待機 |
| `greet.vmd`、`nod.vmd` | 挨拶、うなずき |
| `walk.vmd`、`sit.vmd` | 歩行、着席 |
| `grab.vmd` | 長押しでつまんだとき |

サンプルの `idle`、`walk`、`sit`、`grab` は、組み立て時に `uka3d_motiongen` がモデルの脚の長さ・足の大きさ・腕の角度を測って作ります。ほかのモデルに差し替えたときも、`-ModelDir` を付けて組み立て直せばそのモデル用に作り直されます。

## モデルに合わせてモーションを作る

`uka3d_motiongen` は PMX を読み、そのモデル用の待機・歩行・着席・つまみの VMD を書き出します。どれもこのプロジェクトが計算で作るデータなので、ゴーストと一緒に配布できます。

```powershell
build\msvc-x64\tools\Release\uka3d_motiongen.exe model.pmx ghost\master\3d\motion --check
```

- 歩行は、接地している足が体の進む速さと同じだけ後ろへ動くように作ります。既定では 96dpi で 384×682 の 3D ウィンドウが毎秒 180px 歩く場合に合わせます。別の速さで歩かせるときは `--speed`、ウィンドウの大きさを変えたときは `--width`／`--height` を指定します。
- 歩行速度（`Move3DTo` の 3 番目の引数）は物理ピクセルです。拡大率 150% の画面では 3D ウィンドウも 1.5 倍になるので、速度も 1.5 倍（270）にすると足が滑りません。サンプルの `Uk3dWalkSpeed` は画面の拡大率から計算します。
- `--check` を付けると、歩行中の足の滑りと、床より下に出た頂点の深さを表示します。
- 長いスカートやローブのモデルは、歩くと脚に押されて物理でめくれやすくなります。`--step`（歩幅 / 脚の長さ、既定 0.5）と `--lift`（足を上げる高さ / 脚の長さ、既定 0.055）を小さくし、`--start-crossing`（両脚が交差する所から歩き出す。待機からつながるときに脚が急に開かない）を付けると落ち着きます。例：`--speed 110 --step 0.28 --lift 0.03 --start-crossing`。歩く速さ（`Move3DTo` の第3引数）も `--speed` と同じにしてください。
- 必要なボーンは `左足`／`左ひざ`／`左足首` と右側の同じボーンです。足の大きさは、足首（と `左足首D`）とその子孫のボーン（`左足先EX`、`左つま先EX` など）に付いた頂点から測ります。ない場合は終了コード 2 で終わり、サンプルの組み立てでは汎用のモーションを使います。腕（`左腕`／`右腕`、`左ひじ`／`右ひじ`）、`センター`、`上半身`、`上半身2`、`首`、`頭` は、あれば使います。
- 脚は IK を使わずに角度を計算します。足 IK のあるモデルでも、歩行・待機・着席・つまみの間は足 IK を無効にします。

## YAYA から再生する

サンプルの `ukagaka3d.dic` を読み込んだ辞書で使えます。次の例は挨拶を1回再生したあと待機をループします。待機だけを始めるときは `Play3DMotion("idle")` を使います。

```c
OnMyGreeting
{
    if Play3DMotion("greet", 0, "idle") == 0 {
        return "\0モーションを読み込めませんでした。\e"
    }
    "\0こんにちは。\e"
}
```

- `Play3DMotion` の第2引数は、ループが `1`、1回再生が `0` です。省略時はループします。第3引数は1回再生後に流すモーション名です。
- `_ok = Set3DMorph("笑い", 0.7)` でモーフの重みを設定します。重みは 0〜1 です。解除は `_ok = Reset3DMorph("笑い")`、一括解除は `_ok = Reset3DMorph()` です。
- `_ok = Configure3DGrab("grab", "idle", 180)` は、つまみ・解放後の待機・長押し時間（ms）を指定します。
- 第4引数でカメラトラックを選べます。省略時は自動、`"none"` で使わず、`.camera.json` のパスでそのファイルを使います（次の節）。
- 通常の `Play3DMotion` では、VMD が見つからない場合は失敗を返します。歩行や着席の指示で VMD を省略するか、許可フォルダ内に指定 VMD がなければ、基本姿勢で移動や着席を続けます。

## カメラを動かす（カメラトラック）

VMD と同じフォルダに、同じ名前の `.camera.json` を置くと、そのモーションの再生中にカメラが動きます（例：`think.vmd` と `think.camera.json`）。辞書を書き換える必要はありません。動くのはカメラだけなので、物理演算（髪・スカート）やウィンドウの位置には影響しません。

```json
{
    "version": 1,
    "keys": [
        { "frame": 0 },
        { "frame": 30, "focusBone": "頭", "focusOffset": [0, 0.5, -0.5], "zoom": 1.6, "yaw": 10 },
        { "frame": 110, "focusBone": "頭", "focusOffset": [0, 0.5, -0.5], "zoom": 1.7, "yaw": 12 },
        { "frame": 150, "ease": "smooth" }
    ]
}
```

| 項目 | 意味 |
|---|---|
| `frame` | VMD のフレーム（30 フレーム = 1 秒）。必須 |
| `focus` | 画面の中心（通常のカメラが見ている点）に持ってくるモデル座標 `[x, y, z]`。省略すると通常の位置 |
| `focusBone`、`focusOffset` | `focus` の代わりにボーンを追う。ボーンの今の位置に `focusOffset` を足した点。モデルにそのボーンがなければ通常の位置 |
| `zoom` | 何倍に大きく見せるか（0.2〜8、既定 1）。1 より小さいと引きになる |
| `yaw` | 注目点のまわりに回り込む角度（度）。+ でキャラクターの左側（画面の右）から見る |
| `pitch` | 上下の回り込み（度、−80〜80）。+ で上から見下ろす |
| `ease` | 前のキーからこのキーへの変化のしかた：`smooth`（既定）、`linear`、`in`、`out` |

- キーのない部分は、最初または最後のキーのまま止まります。最後のキーは `{ "frame": …}`（通常のカメラ）に戻しておくと、次のモーションへ自然につながります。
- モーションの切り替え時は、そのときのカメラから 0.25 秒かけて次のモーションのカメラ（トラックがなければ通常のカメラ）へ移ります。
- ループ再生では先頭に戻るとカメラも先頭のキーに戻るので、ループするモーションでは最初と最後のキーを同じにしてください。
- マウスホイールでの拡大縮小、着席中の向き、歩行中の向きはそのまま効き、カメラトラックはその上に重なります。当たり判定は表示に合わせて動きます。着席位置の計算はカメラトラックの影響を受けません。
- 寄りすぎるとモデルがウィンドウの端で切れます。ウィンドウの大きさは変わりません。
- JSON が読めない場合は、ログに警告を出してカメラを動かさずにモーションだけ再生します。第4引数でファイルを指定した場合は失敗を返します。

### MMD のカメラモーションを使う

MMD でカメラを付けて「カメラ・照明」のモーションとして保存した VMD も使えます。`<モーション名>.camera.vmd` の名前で VMD の隣に置くか、第4引数でパスを指定します。`.camera.vmd` と `.camera.json` の両方がある場合は `.camera.vmd` を使います。

- MMD の補間曲線（ベジェ）、距離、注視点、回転、視野角をそのまま使います。
- 当てはめ方は「MMD の初期カメラ（注視点 (0, 10, 0)、距離 45、視野角 30 度）からの差」です。標準的な大きさ（身長 20 前後）のモデルなら MMD で見た構図とほぼ同じになり、そのうえでこのウィンドウの大きさ、ホイールでの拡大縮小、着席・歩行中の向きにも合わせられます。
- 画面の形は MMD（横長）と違うので、上下の写り方は同じで、左右は狭くなります。
- 「パース」のオフ（平行投影）は使えず、いつも遠近法で表示します。
- モーションとカメラは同じフレームで進みます。ダンスなど、カメラの長さがモーションより長いものは、モーションの長さで終わります。

## まばたきと視線

3D ランタイムは、何もしなくても次の 2 つを行います。

- **まばたき**：モーフ「まばたき」（なければ「瞬き」「blink」）を 2〜6 秒ごとに動かします。ときどき 2 回続けます。モーションや表情（`Set3DMorph` など）で「まばたき」「笑い」「ウィンク」などがすでに 0.3 以上かかっている間は休むので、目を閉じた表情と重なりません。モーションに入れたまばたきとも重なりますが、その場合は大きいほうの値になります。
- **視線**：マウスが頭の近くに来ると、首・頭・目をカーソルのほうへ向けます（合わせて左右 40 度、上下 25 度まで。首 3 割、頭 4.5 割、目 2.5 割）。カーソルが顔の上にあるときは見ている人のほうを向きます。離れると 0.6 秒ほどで戻ります。物理演算の前に回すので、頭に付いた髪やフードも一緒に動きます。つまんでいる間と歩いている間は追いません。

使うボーンは「首」「頭」「両目」（なければ「左目」「右目」）です。ないものは使いません。

`ukagaka3d.json` で変えられます。

```json
"face": { "blink": true, "gaze": true, "gazeRadius": 0, "blinkMorph": "まばたき" }
```

| 項目 | 意味 |
|---|---|
| `blink` | 自動まばたき（既定 true） |
| `gaze` | 視線追従（既定 true） |
| `gazeRadius` | 視線が反応する、頭からの距離（96dpi 換算のピクセル）。0 はウィンドウの高さの 6 割 |
| `blinkMorph` | まばたきに使うモーフ名（省略時は「まばたき」「瞬き」「blink」の順に探す） |

辞書からは `_ok = Configure3DFace(1, 0)`（まばたきは ON、視線は OFF）のように切り替えられます。第3引数は反応距離、第4引数はモーフ名で、空の引数は変更しません。
