# 02 モーションと表情

## VMD を置く

サンプルでは VMD を `ghost/master/3d/motion/` に置きます。辞書からは拡張子なしで呼べます。ボーン名が PMX と一致する VMD を使ってください。

| サンプルのファイル | 用途 |
|---|---|
| `idle.vmd` | 待機 |
| `greet.vmd`、`nod.vmd` | 挨拶、うなずき |
| `walk.vmd`、`sit.vmd` | 歩行、着席 |
| `grab.vmd` | 長押しでつまんだとき |

サンプルの `idle`、`walk`、`sit`、`grab` は、組み立て時に `uka3d_motiongen` がモデルの脚の長さ・足の大きさ・腕の角度を測って作ります。ほかのモデルに差し替えたときも、`-ModelDir` を付けて組み立て直せばそのモデル用に作り直されます。

## モデルに合わせてモーションを作る

`uka3d_motiongen` は PMX を読み、そのモデル用の待機・歩行・着席・つまみの VMD を書き出します。どれもこのプロジェクトが計算で作るデータなので、ゴーストと一緒に配布できます。

```powershell
build\msvc-x64\tools\Release\uka3d_motiongen.exe model.pmx ghost\master\3d\motion --check
```

- 歩行は、接地している足が体の進む速さと同じだけ後ろへ動くように作ります。既定では 96dpi で 384×682 の 3D ウィンドウが毎秒 180px 歩く場合に合わせます。別の速さで歩かせるときは `--speed`、ウィンドウの大きさを変えたときは `--width`／`--height` を指定します。
- 歩行速度（`Move3DTo` の 3 番目の引数）は物理ピクセルです。拡大率 150% の画面では 3D ウィンドウも 1.5 倍になるので、速度も 1.5 倍（270）にすると足が滑りません。サンプルの `Uk3dWalkSpeed` は画面の拡大率から計算します。
- `--check` を付けると、歩行中の足の滑りと、床より下に出た頂点の深さを表示します。
- 必要なボーンは `左足`／`左ひざ`／`左足首` と右側の同じボーンです。足の大きさは、足首（と `左足首D`）とその子孫のボーン（`左足先EX`、`左つま先EX` など）に付いた頂点から測ります。ない場合は終了コード 2 で終わり、サンプルの組み立てでは汎用のモーションを使います。腕（`左腕`／`右腕`、`左ひじ`／`右ひじ`）、`センター`、`上半身`、`上半身2`、`首`、`頭` は、あれば使います。
- 脚は IK を使わずに角度を計算します。足 IK のあるモデルでも、歩行・待機・着席・つまみの間は足 IK を無効にします。

## YAYA から再生する

サンプルの `ukagaka3d.dic` を読み込んだ辞書で使えます。次の例は挨拶を1回再生したあと待機をループします。待機だけを始めるときは `Play3DMotion("idle")` を使います。

```c
OnMyGreeting
{
    if Play3DMotion("greet", 0, "idle") == 0 {
        return "\0モーションを読み込めませんでした。\e"
    }
    "\0こんにちは。\e"
}
```

- `Play3DMotion` の第2引数は、ループが `1`、1回再生が `0` です。省略時はループします。第3引数は1回再生後に流すモーション名です。
- `_ok = Set3DMorph("笑い", 0.7)` でモーフの重みを設定します。重みは 0〜1 です。解除は `_ok = Reset3DMorph("笑い")`、一括解除は `_ok = Reset3DMorph()` です。
- `_ok = Configure3DGrab("grab", "idle", 180)` は、つまみ・解放後の待機・長押し時間（ms）を指定します。
- 通常の `Play3DMotion` では、VMD が見つからない場合は失敗を返します。歩行や着席の指示で VMD を省略するか、許可フォルダ内に指定 VMD がなければ、基本姿勢で移動や着席を続けます。
