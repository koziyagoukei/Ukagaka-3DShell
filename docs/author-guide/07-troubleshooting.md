# 07 困ったとき

| 症状 | 確認すること |
|---|---|
| モデルが表示されない | `ghost/master/ukagaka3d_runtime.log` の PMX と描画のエラーを確認します。`ukagaka3d.json` の `model` は `ghost/master` からの相対パスです。アプリの背後にいる場合はメニューで「常に最前面」を試します。 |
| ゴースト切り替えから起動しない | `install.txt` と `ghost/master/descript.txt` の位置、`shiori,yaya.dll` の指定、`yaya.txt` の辞書登録を確認します。組み立て済みフォルダなら SSP の `--ghost` で直接起動して切り分けられます。 |
| `--ghost` で起動したのに別のゴーストが出た | SSP がこのゴーストを読み込む前に既定のゴーストを選んだ状態です（ランタイムと SAORI のログは作られません）。品質改善の検証では 1 回だけ起き、その後の 8 回は再現しませんでした。SSP を終了して起動し直すか、「ゴースト切り替え」から選びます。配布時は NAR をインストールして使ってください。 |
| SAORI が読み込まれない | `ukagaka3d_saori.dll` の x86 版を `ghost/master` に置きます。ランタイムは x64 版です。`ukagaka3d_saori.log` で設定ファイル、ランタイムの起動、接続結果を確認します。 |
| モーションが再生されない | `3d/motion` のファイル名、辞書から渡す名前、PMX と VMD のボーン名を確認します。ログに出る一致トラック数が手がかりになります。 |
| 当たり判定がずれる | `hit-regions.json` の `bone`、`offset`、`radius`、`priority` を確認します。モデル差し替え後は特に、頭の球を一つに絞り、待機と別の姿勢の両方で位置を試します。ランタイムログの `3D 入力` にはクリック・なで・ドラッグで選ばれた部位が出ます。 |
| クリックしても会話が出ない | ログに `3D 入力設定` が出ること、`reference[4]` と設定の `name` が同じこと、同じゴーストを二重に開いていないことを確認します。3D イベントには SSP のローカル Direct SSTP を使います。 |
| バルーンの位置がおかしい | `shell/master/descript.txt` の `sakura.balloon.offsetx` と `sakura.balloon.offsety` を調整します。歩行中は出発位置に留まり、到着時と着席中にモデル側へ移ります。 |
| 物理演算が不自然 | `"physics": false` や Shift＋右クリックから物理を切り替え、基本の VMD 姿勢と比較します。モーションとモデルの剛体・ジョイントの組み合わせを確認してください。 |

ログはゴーストを起動し直したときに更新されます。起動直後に問題がある場合は、再起動前のログを控えると原因を追いやすくなります。
