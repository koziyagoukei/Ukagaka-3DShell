# 01 モデルを用意する

## PMX とテクスチャ

PMX 2.0／2.1 を読み込みます。PMD や VRM を直接読み込む機能はありません。モデルが読み込めても、VMD の動作と表情はモデルのボーン名、モーフ名、ウェイト、物理設定に依存します。

1. 使いたい PMX を PMX エディタで開き、ボーン一覧で `頭` や `上半身`、モーフ一覧で `笑い` などの実際の名前を調べます。判定の位置調整には基本姿勢でのボーン座標も控えます。
2. PMX とテクスチャのフォルダを一緒にコピーします。PMX が `tex/face.png` を参照するなら、`tex` を PMX の隣に置きます。PNG、TGA、BMP などを扱えます。
3. 必要に応じて、ビルドした `pmx_info` でもモーフを一覧できます。

```powershell
.\build\msvc-x64\tools\Release\pmx_info.exe 'C:\MMD\MyModel\MyModel.pmx' --morphs
```

## サンプルで差し替える

1. サンプルの `ghost/master/3d/model/` に、例として `user` フォルダを作ります。そこへ `MyModel.pmx` とテクスチャを入れます。
2. `ghost/master/ukagaka3d.json` の `model` 行を次のように置き換えます。ほかの設定は残してください。

```json
"model": "3d/model/user/MyModel.pmx",
```

3. `ghost/master/hit-regions.json` のボーン名、オフセット、半径をモデルに合わせます。手順は [クリック・なでの設定](03-interactions.md) を参照してください。サンプルの会話にある `笑い` も、モデルのモーフ名に合わせます。
4. ゴーストを起動し直します。バルーン、モーション、表情、頭のクリックを順に試します。組み立て時に差し替える方法は [配布と組み立て](06-distribution.md) を参照してください。

## 物理演算

剛体とジョイントのあるモデルでは、髪や衣装の揺れを計算します。モデルを替えたら待機と着席で体や衣装の重なりを見てください。設定ファイルの `"physics": false`、または Shift＋右クリックのランタイムメニューで、物理 OFF の姿勢と比較できます。
