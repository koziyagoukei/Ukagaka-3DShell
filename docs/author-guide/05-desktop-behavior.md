# 05 デスクトップ上を歩く・座る

サンプルのバルーンで「デスクトップ行動」を開きます。「歩く」で今いる画面を横に進み、端に達した次の指示で向きを変えます。「移動停止」でその位置に留まります。

着席は、座る対象のアプリを先に手前にしてから「手前の窓に座る」を選びます。キャラクターが上端に座り、対象の移動とサイズ変更に追従します。「立つ」か、対象の最小化・終了で着席を解除します。画面上端に近い対象では、キャラクターを表示できる位置まで補正します。

## YAYA から指示する

```c
OnMyDesktopActions
{
    "\0\q[指定位置に歩く,OnMyWalk]　\q[座る,OnMySit]　\q[立つ,OnMyStand]\e"
}

OnMyWalk
{
    _ok = Move3DTo(200, 400, 180, "walk", "idle", 0)
    "\0歩きます。\e"
}

OnMySit
{
    _ok = Sit3DOnWindow("foreground", "top-center", "sit", "idle", "", 0)
    "\0ひと休み。\e"
}

OnMyStand
{
    _ok = Stand3DUp()
    "\0立ち上がりました。\e"
}
```

## 座る位置をモデルに合わせる

キャラクターは、骨盤と太ももの下側が窓の上端に乗るように座ります。衣装が体より下に広がっていて沈んで見える、または浮いて見える場合は、`ghost/master/ukagaka3d.json` の `seat` を調整します。

```jsonc
"seat": { "offsetY": 0.4 }   // 数値を増やすと浮き、減らすと沈む（モデル座標）
```

座らせたまま試すには、辞書から `_ok = Configure3DSeat("", "", 0.6)` のように呼びます（3 番目が上下の補正）。値が決まったら `ukagaka3d.json` に書き写します。スカートの裾など、体以外の部分を座面に乗せたいときは `contactBones` にそのボーン名を足します。項目の一覧は [デスクトップ行動 API](../desktop-behavior.md#着席位置の調整) にあります。

`Move3DTo` の最初の2引数は 3D ウィンドウ左上の画面座標、3番目は毎秒の移動ピクセル数です。サンプルの `walk.vmd` は 96dpi で毎秒 180px のときに足が滑らないように作ってあります。サンプルのメニューでは `Uk3dWalkSpeed()` が画面の拡大率に合わせた速さ（150% なら 270）を返します。歩行停止は `_ok = Stop3DMove()` です。着席位置は `top-left`、`top-center`、`top-right` から選べます。

## 自律行動と複数画面

- 自律行動は初期状態で OFF です。ON にすると待機、歩行、条件に応じた着席を繰り返します。メニューで切り替えるか、`_ok = Set3DAutoBehavior(1, 10, 180, "walk", "idle", "sit", 0.2, 0)` と指定します。停止は `_ok = Set3DAutoBehavior(0, "", "", "", "", "", "", "")` です。
- 画面またぎは初期状態で OFF です。ON にすると「別の画面へ歩く」が使えます。YAYA では `_ok = Set3DCrossMonitor(1)` のあと `_ok = Move3DToNextMonitor(Uk3dWalkSpeed(), "walk", "idle")` とします。着席中は、対象の窓が別画面へ移動しても追従します。
- 必要に応じてメニューで「常に最前面」を切り替えられます。

引数や状態名の一覧は [デスクトップ行動 API](../desktop-behavior.md) を参照してください。
