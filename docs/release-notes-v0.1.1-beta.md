伺か（SSP）のゴーストを MMD の PMX モデルで 3D 表示するランタイムの、ベータ版の更新です。
無料・非営利のオープンソースプロジェクトで、ライセンスは MIT です。

> ベータ版です。作者の環境（Windows 11、内蔵 GPU 1 台、SSP 2.9.33、YAYA 6.8.3）で確認した範囲で公開します。

## 新しい機能

- **カメラトラック**：VMD と同じ名前の `.camera.json` を置くと、そのモーションの間カメラが寄ったり回り込んだりします。注目点はボーンで指定でき、動きに追従します。MMD で作ったカメラモーション（`.camera.vmd`）も、MMD の初期カメラからの差として当てはめるので、ほぼ同じ構図になります。動くのはカメラだけで、髪やスカートの物理には影響しません
- **自動まばたき**：モーフ「まばたき」で 2〜6 秒ごとにまばたきします。表情やモーションで目を閉じている間は休みます
- **視線追従**：マウスが頭の近くに来ると、首・頭・目をそちらへ向けます。物理演算の前に回すので、髪も一緒に動きます
- 設定は `ukagaka3d.json` の `face`、辞書からは `Configure3DFace`。カメラは `Play3DMotion` の第4引数で、使わない・別のファイルを指定できます
- **モーション生成**：`uka3d_motiongen` に `--step`（歩幅）、`--lift`（足を上げる高さ）、`--start-crossing`（脚が交差する所から歩き出す）。長いスカートやローブが歩行でめくれ上がるのを抑えられます
- **サンプルゴースト**：メニューに「まばたき」「目で追う」の切り替え。あいさつで顔へ寄るカメラの例

## 確認済みと未確認

- **確認済み**：0.1.0-beta の項目に加えて、SSP でのカメラトラック（寄り・回り込み・切り替えのつなぎ）、MMD 製カメラモーションの距離・注視点・上下の回転・視野角、まばたき、視線追従（カーソルは自動操作）、物理つきの描画での小さい歩幅の歩行
- **未確認**：MMD カメラの左右の回り込みと傾き（ロール）の向き（MMD 本体との見比べ）、人の手による操作感、里々からの利用、Windows 10・ほかの GPU

詳しくは README の「対応状況」と、CHANGELOG をご覧ください。
